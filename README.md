# LED Push Button

My first Arduino project using a push button to control an LED.

## Components Used

- Arduino Uno
- LED
- Push button
- Resistor
- Breadboard
- Jumper wires

## What I Learned

- Digital input and output
- Using a push button with Arduino
- Controlling an LED using code
- Basic breadboard connections
